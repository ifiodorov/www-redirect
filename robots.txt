# www - это витрина только для мессенджеров: og-шимы, которые редиректят

# prosto-finance.ru.
#
# Запретов здесь СОЗНАТЕЛЬНО нет (было до 17.09.2026 - по одному Disallow на
# каждого поисковика). Запрет в robots.txt не прячет страницу, а только не даёт
# её скачать: Google, узнав адрес со стороны, всё равно кладёт его в индекс -
# пустой строкой, без описания, и убрать её оттуда нечем, потому что noindex он
# тоже не скачает. Ровно это и случилось с корнем www (письмо Search Console
# от 15.09.2026).
#
# Теперь наоборот: робот заходит свободно, читает в каждом шиме
# <meta name="robots" content="noindex"> и выбрасывает адрес из индекса.
# Мета-тег ставит генератор шимов, наличие проверяет tools/verify_shims.py.

#
